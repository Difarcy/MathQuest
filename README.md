# MathQuest – Game Edukasi KPK dan FPB

**MathQuest** merupakan game edukasi yang dirancang untuk membantu meningkatkan minat belajar siswa kelas V Sekolah Dasar dalam mempelajari materi **Kelipatan Persekutuan Terkecil (KPK)** dan **Faktor Persekutuan Terbesar (FPB)**.

Game ini menghadirkan pembelajaran matematika melalui materi interaktif, permainan edukatif, kuis, dan ujian. Dengan pendekatan *Game-Based Learning*, siswa dapat mempelajari konsep matematika sekaligus berlatih melalui aktivitas permainan.

## Status Pengembangan

**Dalam Pengembangan (In Development)**

MathQuest saat ini masih dalam tahap pengembangan menggunakan Unity. Proses pengerjaan mencakup implementasi materi pembelajaran, mekanisme permainan, kuis, ujian, serta antarmuka pengguna. Pengembangan dilakukan secara bertahap hingga seluruh fitur dapat berjalan sesuai dengan rancangan.

## Tujuan Proyek

Proyek ini bertujuan untuk merancang dan membangun media pembelajaran berbentuk game edukasi yang dapat mendukung proses pembelajaran matematika, khususnya pada materi KPK dan FPB untuk siswa kelas V Sekolah Dasar.

## Fitur Utama

- **Belajar** – Menyajikan materi pembelajaran KPK dan FPB secara bertahap.
- **Bermain** – Menyediakan berbagai permainan edukatif untuk membantu siswa memahami konsep faktor dan kelipatan bilangan.
- **Kuis** – Menguji pemahaman siswa melalui pertanyaan pilihan ganda.
- **Ujian** – Menyediakan evaluasi pembelajaran dengan sistem soal, penilaian, dan umpan balik.

## Materi Pembelajaran

Materi yang disajikan meliputi:

1. Faktor Bilangan
2. Kelipatan Bilangan
3. Bilangan Prima
4. Faktorisasi Prima
5. Faktor Persekutuan
6. Kelipatan Persekutuan
7. Faktor Persekutuan Terbesar (FPB)
8. Kelipatan Persekutuan Terkecil (KPK)
9. Pohon Faktor dan Tabel
10. Cerita KPK dan FPB

## Teknologi yang Digunakan

- **Unity** – Game engine untuk membangun aplikasi.
- **C#** – Bahasa pemrograman untuk mengembangkan mekanisme dan interaksi game.
- **Adobe Photoshop** – Digunakan untuk kebutuhan pengolahan aset visual.
- **Git dan GitHub** – Digunakan untuk pengelolaan versi dan penyimpanan kode sumber proyek.

## Cara Menjalankan Proyek

1. Unduh atau clone repository ini:

   ```bash
   git clone https://github.com/Difarcy/MathQuest.git
   ```

2. Buka **Unity Hub**.
3. Pilih **Add Project from Disk**.
4. Pilih folder hasil clone repository `MathQuest`.
5. Buka proyek menggunakan versi Unity yang sesuai dengan konfigurasi proyek.
6. Jalankan aplikasi melalui Unity Editor.
